# ASH Pattern System Windows SDK

This product provides nine APS semantic modules as a native C++20 static library, `ash-core.lib`, plus caller-owned bounded support diagnostics. SDK version `1.0.0-rc.1` targets separate x64 and ARM64 Release assets.

The adopted binding is canonical APS `1.0.0-rc.3` at `50d7e5ab88932a4a967ffc2c83bd18fae45b73c8`, with engineering policy `0.7.0` and a separate realization-profile catalog `0.7.2`. This corrected immutable authority resolves the historical rc.1 diagnostic-notes and containment-breach contradictions. Release acceptance must be established by the exact released `qualification.json`, bound to its clean source and asset bytes. Historical totals are not current release evidence; any mandatory core failure still blocks publication.

Native diagnostic records carry structured facts and recomputed semantic identities. Typed containment/halt projections preserve complete causal evidence and local UTC entry/adoption time; independent imported histories are retained for separate audit export. Debug-only source contains the actual rich support collector, while public Release libraries contain minimal essential collection.
